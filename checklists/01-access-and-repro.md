# 1 — Access and reproduce

- [ ] Repository URL received (or invite accepted) and branch confirmed.
- [ ] Hosting platform identified: AI Studio, Replit, Vercel, Firebase, other.
- [ ] Tool that generated the app identified.
- [ ] Problem described by the client: expected behaviour vs current behaviour.
- [ ] Problem reproduced locally **and** in the deployed environment.
- [ ] Browser console and network tab captured (errors, failed requests, 4xx/5xx).
- [ ] Deployment logs checked (build step, runtime logs, environment variables).
- [ ] Scope compared with the hired tier; client notified before work if larger.
- [ ] Baseline recorded: what already worked before any change.

Output of this step: a short written confirmation of the problem and scope.
