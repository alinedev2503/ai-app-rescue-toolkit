# 5 — Handover

Every delivered fix includes:

- [ ] Live URL and repository link.
- [ ] List of changed files with a one-line reason for each.
- [ ] Root cause of the original problem, in plain language.
- [ ] Which keys were moved and which ones the client must rotate.
- [ ] New environment variable names, if any.
- [ ] How to run locally and how to redeploy.
- [ ] What was **not** changed and why (scope honesty).
- [ ] Confirmation that the source code belongs to the client after payment.
